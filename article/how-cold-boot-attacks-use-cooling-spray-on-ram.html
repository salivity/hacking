How Cold Boot Attacks Use Cooling Spray on RAM

A cold boot attack is a physical side-channel exploit where an attacker extracts volatile data from a computer's Dynamic Random-Access Memory (DRAM) after powering the machine off. Under normal room-temperature conditions, DRAM loses its electrical charge and held data within seconds of losing power. However, by applying physical cooling sprays—such as inverted canned air or liquid nitrogen—to the memory modules, attackers drastically slow down the decay of residual electrical charges. This allows the retained memory contents, which often include full-disk encryption keys and sensitive credentials, to be read and reconstructed.

The Mechanics of DRAM Data Retention

DRAM stores individual bits of data as electrical charges inside millions of tiny microscopic capacitors paired with transistors. Because these capacitors naturally leak charge over time, standard memory controllers continuously refresh them thousands of times per second to maintain data integrity.

When power is abruptly cut, these refresh cycles stop, and the capacitors begin discharging. Contrary to the assumption that volatile memory disappears instantly upon losing power, the degradation process takes anywhere from a few hundred milliseconds to several seconds at ambient room temperature. This phenomenon is known as data remanence.

How Cooling Sprays Delay Memory Decay

The rate at which a DRAM capacitor leaks its charge is directly tied to temperature. At higher temperatures, electron movement is faster, accelerating the leakage. When the temperature drops, electron mobility slows significantly, causing the discharge rate of the capacitors to decrease exponentially.

Attackers exploit this physical property using cooling agents:

  1. Physical Application: The attacker exposes the computer's motherboard while the machine is running or immediately after cutting power, and sprays the DRAM chips directly using compressed refrigerant spray (commonly an inverted canister of compressed gas duster) or liquid nitrogen.
  2. Temperature Drop: An inverted aerosol duster dispenses liquefied propellant (such as difluoroethane), which rapidly boils off and drops the temperature of the chip packages down to approximately -50°C (-58°F). Liquid nitrogen can lower the temperature below -190°C.
  3. Extended Retention Window: At sub-zero temperatures, the data remanence window expands dramatically. Instead of degrading in a matter of seconds, the capacitors retain their charges with minimal bit decay for several minutes at -50°C, and for hours or days when submerged in liquid nitrogen.

Executing the Memory Extraction

Once the memory chips are frozen, the attacker carries out one of two extraction methods:

  • In-System Reboot: The attacker performs a hard reset of the machine without cutting off power long enough for the modules to warm up. The system is then forced to boot from an external USB drive containing a lightweight operating system designed to read the contents of physical memory and write them to a storage device before the operating system or BIOS can overwrite them.
  • DIMM Transposition: The attacker powers off the machine, physically unseats the frozen RAM sticks from the victim's motherboard, and quickly inserts them into an adjacent machine controlled by the attacker. This target machine immediately dumps the residual memory contents to a disk image.

Recovering Encrypted Data

Because the physical cooling prevents significant bit degradation, the resulting memory dump contains nearly intact data structures. Software tools are then used to scan the raw binary dump for cryptographic signatures.

Full-disk encryption solutions—such as BitLocker, FileVault, and LUKS—must keep their master encryption keys in plaintext within RAM while the volume is mounted to allow the operating system to read and write files on the fly. Attackers use automated key-finding algorithms to locate the symmetric AES keys within the dumped image, reconstruct any small bit-rot errors caused by partial capacitor discharge, and unlock the victim's encrypted drives without ever needing the user's password.
