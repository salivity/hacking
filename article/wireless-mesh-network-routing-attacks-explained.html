Wireless Mesh Network Routing Attacks Explained

Decentralized wireless mesh networks (WMNs) rely on peer nodes to dynamically discover paths and relay data packets without a centralized authority. When adversaries leverage software-defined radios (SDRs) or rogue transceivers to inject, alter, or manipulate radio frequency (RF) transmissions, they can exploit the underlying routing protocols. These routing attacks degrade network reliability, introduce latency, cause severe packet loss, and partition the network.

Blackhole and Grayhole Attacks

In a blackhole attack, a compromised node exploits route discovery protocols—such as Ad hoc On-Demand Distance Vector (AODV) or Optimized Link State Routing (OLSR)—by falsely advertising the shortest or most optimal route to a destination. Once traffic is redirected to the rogue node, it drops all packets silently instead of forwarding them.

A grayhole attack is a stealthier variant where the rogue node drops packets selectively—such as dropping specific protocol data, packets from targeted IP addresses, or dropping traffic at random intervals—making the disruption harder to detect by automated fault-detection systems.

Wormhole Attacks

A wormhole attack requires an attacker to capture radio packets at one location in the mesh, tunnel them through an out-of-band, low-latency link (such as an unauthorized directional RF link or wired Ethernet), and replay them at another distant location. This creates the illusion that two distant nodes are direct neighbors. Because the tunneled path appears faster, the routing protocol routes significant network traffic through the wormhole. Once established, the attacker can eavesdrop, selectively drop packets, or suddenly sever the link to cause network-wide route recalculations and instability.

Sinkhole Attacks

In a sinkhole attack, an adversary uses radio transmission manipulation to make a compromised node appear exceptionally attractive to surrounding nodes. The attacker broadcasts forged routing metrics, such as an artificially low hop count, high link quality, or maximum battery reserves. Surrounding nodes update their routing tables to route their traffic through this "sink." Once the attacker attracts a critical volume of mesh traffic, they can execute eavesdropping, traffic analysis, or combine the exploit with a blackhole attack.

Sybil Attacks

Decentralized networks rely on peer identity and consensus to make routing decisions. In a Sybil attack, a single radio node illegitimately claims multiple identities by forging physical MAC addresses or cryptographic keys. By presenting itself as multiple distinct nodes, the attacker can manipulate multi-path routing protocols, disproportionately influence distributed routing decisions, outvote legitimate nodes, and bypass geographic routing algorithms.

Rushing Attacks

On-demand routing protocols suppress duplicate Route Request (RREQ) packets to prevent broadcast storms, meaning nodes only forward the first RREQ received for a particular route discovery sequence. An attacker executes a rushing attack by utilizing specialized radio hardware to relay RREQ packets faster than legitimate nodes—often bypassing local medium access control (MAC) delays or using higher transmission power. As a result, the attacker’s forwarded RREQ reaches neighboring nodes first, causing legitimate route discovery requests to be discarded and ensuring the final route traverses the attacker.

Route Poisoning and State Exhaustion

Attackers can transmit spoofed routing update messages to alter legitimate topology maps. By injecting fake route errors (RERR) or advertising unreachable metrics for active nodes, attackers break existing paths and force constant route discoveries. This triggers state exhaustion, where constrained mesh radios deplete their processing power, memory, and battery reserves handling endless control-plane overhead, ultimately leading to physical node failure and network collapse.
